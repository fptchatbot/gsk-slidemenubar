Layanan

📧

Gmail

Layanan email profesional dari Google yang mudah digunakan untuk kebutuhan bisnis maupun personal.

  • Email dengan nama domain perusahaan sendiri
  • Kotak masuk otomatis terorganisir
  • Notifikasi pengingat pesan belum dibaca
  • Fitur Snooze untuk menunda email
💾

Google Drive

Penyimpanan cloud yang memungkinkan kamu menyimpan dan berbagi file dari mana saja.

  • Penyimpanan hingga 15 GB gratis
  • Berbagi file dengan mudah lewat link
  • Akses dari semua perangkat
  • Kolaborasi real-time bersama tim
📄

Google Docs

Buat dan edit dokumen langsung di browser tanpa perlu install software tambahan.

  • Edit bersama secara bersamaan
  • Riwayat versi dokumen tersimpan otomatis
  • Tersedia Docs, Sheets, dan Slides
  • Kompatibel dengan format Microsoft Office
🎥

Google Meet

Platform video conference yang aman dan mudah digunakan untuk rapat online.

  • Video call hingga 100 peserta (gratis)
  • Tidak perlu install aplikasi
  • Integrasi langsung dengan Google Calendar
  • Fitur share screen dan rekam rapat
